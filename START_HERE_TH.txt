BATTLAB - เริ่มต้นใช้งาน
=========================

อัปเดตเวอร์ชันใหม่โดยไม่ล้างค่าที่ตั้งไว้ (Wi-Fi, รหัสจับคู่, ทัช, BMS):
- บอร์ดจอ: UPDATE_CYD35_WINDOWS.bat   |   บอร์ด S3: UPDATE_S3_WINDOWS.bat
- ใช้ FLASH_..._WINDOWS.bat เฉพาะติดตั้งครั้งแรก หรือเมื่อบอร์ดเปิดไม่ขึ้น

มีเฟิร์มแวร์ 2 แบบ เลือกให้ตรงกับบอร์ด:

1) บอร์ดจอ 3.5 นิ้ว ESP32-3248S035 (ESP32 ธรรมดา, ชิป USB CH340)
   - ดับเบิลคลิก FLASH_CYD35_WINDOWS.bat
   - ไฟล์: firmware\BATTLAB_CYD35_INSTALL.bin
   - จอแสดงแดชบอร์ด 3 หน้า (ภาพรวม / เซลล์ / ข้อมูลระบบ) แตะจอเพื่อเปลี่ยนหน้า

2) ESP32-S3 DevKitC-1 (ไม่มีจอ)
   - ดับเบิลคลิก FLASH_S3_WINDOWS.bat
   - ไฟล์: firmware\BATTLAB_S3_BLEFIX_INSTALL.bin

ทั้งสองแบบ:
- ต่อ Wi-Fi ชื่อ BATTLAB (ไม่มีรหัส) แล้วเปิด http://192.168.4.1
- รองรับ JK, ANT (โปรโตคอลใหม่) และ JBD / Xiaoxiang Smart BMS
- ปิดแอป BMS บนมือถือก่อนเชื่อมต่อ

ถ้าภาพบนจอกลับด้าน กลับซ้ายขวา หรือสีเพี้ยน:
- ต่อ Wi-Fi BATTLAB แล้วเปิดลิงก์ทีละอัน (บอร์ดจะรีบูตเอง)
  หมุนจอ:        http://192.168.4.1/api/display?rotation=3   (ลอง 1, 3, 5, 7)
  สีกลับขาวดำ:   http://192.168.4.1/api/display?invert=1
  แดงสลับน้ำเงิน: http://192.168.4.1/api/display?rgb=1

ไฟ RGB บนบอร์ด (ทั้งสองแบบ):
- หน้าเว็บ: เมนู "ไฟ RGB" เปิด/ปิด เลือกสี 8 สี โหมด Rainbow / Solid / Breathe / Status และความสว่าง 4 ระดับ
- บอร์ดจอ: แตะแถบบนสุดเพื่อเปลี่ยนหน้าไปหน้าที่ 4 (LED) แล้วกดปุ่มบนจอได้เลย
- ค่าที่ตั้งจะจำไว้หลังรีสตาร์ต

ทัชสกรีน (บอร์ดจอ):
- เปิดครั้งแรกจะให้แตะปลายลูกศร 4 มุมเพื่อตั้งค่าทัช
- ตั้งใหม่: ไปหน้า Info แล้วกดค้าง 4 วินาที หรือเปิด http://192.168.4.1/api/display?calibrate=1

ใช้บอร์ดจอแบบไม่ต้องใช้เว็บ (v1.7.0 ขึ้นไป):
แถบเมนูล่างจอ: HOME | CELLS | BMS | PARAM | LED | SETUP | INFO
- BMS: กด SCAN แล้วแตะชื่อ BMS เพื่อเชื่อม (เลือก Protocol ก่อนได้ ปกติใช้ AUTO)
       AUTO = หา BMS ที่อยู่ใกล้ตัวเดียวแล้วเชื่อมเอง, STOP = หยุดเชื่อมต่อ
       แถบสีฟ้าหน้ารายการ = อุปกรณ์ที่น่าจะเป็น BMS
- SETUP: ความสว่างจอ, หมุนจอ 180 องศา, พักจอ (แตะเพื่อปลุก), เปิด/ปิด Wi-Fi,
         ตั้งค่าทัช, แจ้งเตือน SOC ต่ำ/อุณหภูมิสูง + เสียงบี๊บ (ต่อลำโพงที่ช่อง SPEAK), รีสตาร์ต
- ปิด Wi-Fi แล้วหน้าเว็บจะใช้ไม่ได้ เปิดกลับได้ที่ SETUP

แก้พารามิเตอร์ BMS (หน้า PARAM, v1.9.0 ขึ้นไป):
- JK: แก้ OVP/UVP, recovery, power off, balance, กระแสสูงสุด, อุณหภูมิป้องกัน, ความจุ
  กด - / + (กดค้างเพื่อเลื่อนเร็ว) ค่าที่แก้เป็นสีส้ม แล้วกด SET -> ยืนยัน WRITE
- ทุกยี่ห้อ: ปุ่ม CHG / DSG (และ BAL สำหรับ JK/ANT) เปิด/ปิด MOSFET ต้องกดยืนยันก่อน
- ระบบจะปฏิเสธค่าที่อยู่นอกช่วงปลอดภัย หรือขัดกันเอง (เช่น OVP ต่ำกว่า OVP recovery)
- ปิด DSG = ตัดไฟออกจากแบต อุปกรณ์ที่ต่ออยู่จะดับทันที

BattLab Cloud - ดูแบตจากที่ไหนก็ได้ (v2.0.0 ขึ้นไป):
1. บนจอ: INFO -> HOME WI-FI -> แตะชื่อ Wi-Fi บ้าน -> พิมพ์รหัส -> CONNECT
   (บอร์ด S3: หน้าเว็บ 192.168.4.1 -> ตั้งค่า -> Wi-Fi บ้าน และ BattLab Cloud)
2. บนจอ: INFO -> CLOUD PAIRING จะเห็นรหัสจับคู่ เช่น K7Q2-9XMA
3. บนมือถือ: เปิด https://nakon1122.github.io/battlab-cloud/ -> สมัคร/เข้าสู่ระบบ
   -> เพิ่มอุปกรณ์ -> กรอกรหัสจับคู่
- ส่งข้อมูลทุก 10 วินาที, เก็บกราฟย้อนหลังนาทีละจุด 30 วัน
- เว็บคลาวด์ดูได้อย่างเดียว ไม่สั่งงาน BMS จากระยะไกล

ควบคุมบอร์ดจากเว็บ BattLab Cloud (v2.1.0 ขึ้นไป):
- เปิดเว็บ -> เลือกอุปกรณ์ -> แท็บ "ควบคุม": สวิตช์ MOS, พารามิเตอร์ JK, เชื่อม BMS, ไฟ RGB,
  หน้าจอ, Wi-Fi/ฮอตสปอต, รีสตาร์ท (ขณะเปิดหน้านี้บอร์ดตอบสนองภายใน 3-5 วินาที)

จอ BattLab CLOUD SCREEN (เฟิร์มแวร์แบบที่ 3 สำหรับบอร์ดจอ 3.5 นิ้ว, v2.2.0):
- จอนี้ไม่ต่อ BMS เอง แต่ดึงข้อมูลแบต "ทุกก้อน" ในบัญชี BattLab Cloud มาแสดง และสั่งงานผ่าน cloud ได้
- ติดตั้ง: FLASH_CLOUDSCREEN_WINDOWS.bat (ครั้งแรก) / UPDATE_CLOUDSCREEN_WINDOWS.bat (อัปเดต)
- เปิดครั้งแรก: แตะ 4 มุมตั้งค่าทัช -> เลือก Wi-Fi บ้าน -> พิมพ์รหัส -> CONNECT
- จอจะขึ้นรหัสจับคู่ (PAIR CODE) -> บนเว็บกด "เพิ่มอุปกรณ์" แล้วกรอกรหัสนี้
- แถบเมนู: ALL (แบตทุกก้อน แตะเพื่อเปิด) | HOME | CELLS | GRAPH (กราฟย้อนหลัง 6ชม/24ชม/7วัน)
           | CONTROL (MOSFET / PARAMS / LED / BOARD) | SETUP
- ปุ่ม < > มุมขวาบน = เปลี่ยนไปดูแบตก้อนถัดไป
- แจ้งเตือนเสียง: SOC ต่ำ / อุณหภูมิสูง / แบตออฟไลน์เกิน 5 นาที (ตั้งที่ SETUP)
- ถ้าจะกลับไปใช้เป็นจอต่อ BMS ปกติ: FLASH_CYD35_WINDOWS.bat

v2.3.0 - ชื่อบอร์ดไม่ซ้ำกันแล้ว + ตั้งค่าผ่านบลูทูธ:
- Wi-Fi ฮอตสปอตและชื่อบลูทูธของแต่ละบอร์ดเป็น BATTLAB-XXXX (XXXX มาจากเลข MAC ของบอร์ดนั้น)
  ใช้หลายบอร์ดพร้อมกันได้ไม่ชนกัน (ดูชื่อบนจอ CYD ได้ที่ INFO -> CLOUD PAIRING)
- ตั้งค่าผ่านบลูทูธ: เปิดเว็บ BattLab Cloud -> "ตั้งค่าบอร์ดผ่านบลูทูธ" -> เลือก BATTLAB-XXXX
  ทำได้: ตั้ง/ลืม Wi-Fi บ้าน, ดูรหัสจับคู่ + เพิ่มเข้าบัญชี, สวิตช์ MOS, พารามิเตอร์ JK, เชื่อม BMS, ไฟ RGB, รีสตาร์ท
  ใช้ได้กับ Chrome บน Android และ Chrome/Edge บนคอม (iPhone ใช้แอป Bluefy)
- ติดตั้งเว็บเป็นแอป: ปุ่ม "ติดตั้งแอป" บนเว็บ (Android ติดตั้งได้ทันที / iPhone มีขั้นตอนบอก)
- จอ CYD: นาฬิกามุมขวาบน (ต้องต่อ Wi-Fi บ้าน), แตะหน้าปัด SOC = โหมดตัวเลขใหญ่, ลูกศรวิ่งบอกชาร์จ/จ่าย,
  กราฟกำลังไฟ 10 นาทีล่าสุด, เวลาที่เหลือจนเต็ม/หมด
- จอ Cloud Screen: นาฬิกา, โหมดตัวเลขใหญ่, SETUP -> SHOW ON = หน้า HOME วนแสดงแบตทุกก้อน,
  พลังงานวันนี้ (kWh เข้า/ออก), กราฟ SOC เล็กในหน้า HOME, กำลังรวมทุกก้อนบนหัวจอ

v2.4.0 - อัปเดตเฟิร์มแวร์ผ่าน cloud (ไม่ต้องเสียบ USB):
- ครั้งแรกครั้งเดียว: เสียบ USB แล้วรัน UPDATE_*.bat ของบอร์ดนั้น (ค่าที่ตั้งไว้ยังอยู่)
  บอร์ดจอ CYD จะถูกเปลี่ยนตารางพาร์ทิชันให้รองรับการอัปเดตผ่านเน็ตในขั้นตอนนี้
- หลังจากนั้น: เว็บ BattLab Cloud -> เลือกอุปกรณ์ -> ควบคุม -> การ์ด "เฟิร์มแวร์" -> อัปเดตเป็นเวอร์ชันใหม่
  จอ Cloud Screen: หน้า "อุปกรณ์ของฉัน" -> ส่วน จอ Cloud Screen -> ปุ่ม ⬆ หรือบนจอ SETUP -> PAIRING -> UPDATE
- บอร์ดดาวน์โหลดเองผ่าน Wi-Fi บ้าน (~1 นาที) จอแสดงแถบความคืบหน้า แล้วรีสตาร์ทเอง
- ถ้าเวอร์ชันใหม่ค้าง/รีสตาร์ทผิดปกติ 3 ครั้งติด บอร์ดกลับไปใช้เวอร์ชันเดิมเอง

v2.5.0 - ตั้งค่าพารามิเตอร์ ANT และ JBD ได้แล้ว:
- JBD / Xiaoxiang: 22 ค่า (OVP/UVP เซลล์และแพ็ก + ค่าคืนตัว, กระแสชาร์จ/จ่าย, อุณหภูมิ 8 ค่า, บาลานซ์, ความจุ)
  เขียนลง EEPROM ของ BMS แล้วอ่านกลับมาตรวจทุกครั้ง
- ANT (โปรโตคอล BLE รุ่นใหม่): อ่านได้ 47 ค่า (OVP/UVP 2 ระดับ, เตือน, กระแส+หน่วงเวลา, ลัดวงจร, SOC, บาลานซ์, ความจุ)
  การเขียนเป็นโหมดทดลอง: บอร์ดอ่านค่ากลับมาตรวจ ขึ้น "Verified" = BMS รับค่าแล้ว, "Not changed" = BMS ไม่รับ
- ใช้ได้ทุกที่: จอ CYD หน้า PARAM, เว็บ Cloud แท็บควบคุม, ตั้งค่าผ่านบลูทูธ, จอ Cloud Screen CONTROL > PARAMS
- ค่าทั้งหมดถูกอ่านเองหลังเชื่อม BMS ~5 วินาที หรือกด READ / อ่านค่าใหม่

v2.5.1 - แก้จอสแกน Wi-Fi ไม่เจอหลังอัปเดต (ตอนบอร์ดกำลังพยายามต่อ Wi-Fi เดิมที่ไม่มีอยู่)

v2.6.0 - JK BMS ผ่านสาย RS485 (เฉพาะบอร์ด ESP32-S3):
- รองรับ JK-PB / JK Inverter BMS (อ่าน+ตั้งค่า) และ JK รุ่นเก่าที่มีพอร์ต RS485 (อ่านอย่างเดียว)
- ต้องมีโมดูล RS485-to-TTL (MAX485 แบบปรับทิศทางอัตโนมัติ หรือ MAX3485 3.3V)
- ต่อสาย:
    โมดูล TXD (RO) -> ESP32-S3 GPIO18 (RX)
    โมดูล RXD (DI) -> ESP32-S3 GPIO17 (TX)
    โมดูล VCC      -> 3.3V   ,  GND -> GND
    โมดูล A+ / B-  -> พอร์ต RS485 ของ JK (A ต่อ A, B ต่อ B)
  ถ้าต่อ TX/RX สลับ บอร์ดจะลองสลับขาให้เองหลังไม่ได้รับคำตอบ ~8 ครั้ง
- ตั้งค่า: เว็บ BattLab Cloud -> เลือกอุปกรณ์ -> ควบคุม -> การ์ด "ช่องทางเชื่อม BMS" -> สาย RS485
  ค่าเริ่มต้น RX 18, TX 17, 115200, Address 1 (ตาม DIP switch ของ BMS; JK-PB ตัวแรกในกลุ่มขนานมักเป็น 1)
  กดบันทึก บอร์ดเปลี่ยนไปอ่านผ่านสายทันที (บลูทูธ BMS หยุดทำงาน) จะกลับไปบลูทูธก็กดชิป "บลูทูธ"
- ถ้าขึ้น RS485_NO_ANSWER: ตรวจ A/B สลับ, address, ความเร็ว (JK รุ่นเก่ามัก 115200) และ GND ร่วม
- จอ CYD ยังใช้บลูทูธเหมือนเดิม (ขา RS485 ของบอร์ด CYD ไม่ว่าง)

v2.7.0 - แบตหลายลูกบนสาย RS485 เส้นเดียว (ESP32-S3 1 บอร์ด ดูได้สูงสุด 16 ลูก):
- กรณีมีลูกหลัก (DIP 0) ต่อ CAN ไปอินเวอร์เตอร์ และลูกอื่นตั้ง DIP 1,2,3,4:
    เสียบสายจากบอร์ด RS485-to-TTL เข้าช่อง RS485 ที่ว่าง (พอร์ตต่อขนาน RS485-2) ของลูกไหนก็ได้ในสายพ่วง
    บอร์ดจะ "ฟังอย่างเดียว" ข้อมูลที่ลูกหลักถามลูกอื่น -> ได้ทุกลูกรวมลูกหลัก โดยไม่ส่งอะไรแทรก
    ลูกหลักยังคุย CAN กับอินเวอร์เตอร์ได้ตามปกติ · โหมดนี้อ่านอย่างเดียว (ตั้งค่าผ่านแอป JK)
- กรณีไม่มีลูกหลัก (ทุกลูก DIP 1..15): เลือก "บอร์ดถามเอง" + ใส่ address ลูกแรกและจำนวนลูก -> อ่าน+ตั้งค่าได้ทีละลูก
- ตั้งค่า: เว็บ -> ควบคุม -> ช่องทางเชื่อม BMS -> สาย RS485 -> "แบตหลายลูกบนสายเดียว" = อัตโนมัติ (แนะนำ)
  อัตโนมัติ = ฟังสาย 16 วินาทีก่อน ถ้ามีลูกหลักถามอยู่ จะฟังอย่างเดียว ถ้าไม่มีจะถามเอง
- เว็บ: หน้าภาพรวมแสดงยอดรวมทั้งแบงก์ + การ์ดทุกลูก · แท็บเซลล์ เลือกดูทีละลูก · กราฟ เลือก "ทั้งแบงก์" หรือรายลูก
- จอ Cloud Screen: แท็บ CELLS มีปุ่ม #0..#4 แตะเพื่อดูเซลล์แต่ละลูก

v2.8.0 - รุ่นรวมใหญ่:
- RS485 + บลูทูธในบอร์ด S3 ตัวเดียว: RS485 อ่านทุกลูกตลอด บลูทูธใช้ตั้งค่าทุกลูก (รวมลูกหลัก #0)
  เว็บ -> ควบคุม -> การ์ด "บลูทูธของแต่ละลูก" -> จับคู่อัตโนมัติ (ปิดแอป JK บนมือถือก่อน ~1 นาที)
  จับคู่ด้วยหมายเลขเครื่อง (Serial) ของ BMS ถ้าหาไม่เจอจะเทียบรอบชาร์จ/SOC/แรงดันเซลล์แทน
  ตั้งค่าแต่ละลูก: บอร์ดเชื่อมบลูทูธ เขียนค่า อ่านกลับมาตรวจ แล้วตัดการเชื่อม (~10 วินาที)
- แก้: โหมดอัตโนมัติฟังสาย 40 วินาที และถ้ามีข้อมูลใดๆ บนสายจะฟังอย่างเดียว (ไม่ส่งชนลูกหลัก)
  ไม่สลับขา RX/TX เองถ้าเคยอ่านได้แล้ว · จอ CYD ประหยัด RAM · บอร์ด S3 จองหน่วยความจำตามจำนวนลูกจริง
- DALY BMS: รุ่นใหม่ (H/K/M/S, โปรโตคอล D2) และรุ่นเก่า (A5) อ่านค่า + สั่ง MOS ได้
  ผ่านบลูทูธ (S3 และจอ CYD: ปุ่ม DALY ในหน้า BMS) และผ่านสาย RS485/UART (S3: เลือกยี่ห้อในการ์ด RS485)
  ถ้าบลูทูธ DALY ไม่เจอ: ในแอป DALY ปิดโหมด Wi-Fi/Cloud (กดค้างที่อุปกรณ์ -> ลบ)
- ประเภทการใช้งาน: เว็บ -> ตั้งค่า -> การใช้งานและกรุ๊ป (โซลาร์ / มอเตอร์ไซค์ EV / รถไฟฟ้า / สำรองไฟ / แคมป์)
  แบบ EV: ใส่ Wh/กม. -> จอแสดงระยะทางที่เหลือ หน้าปัดกำลังไฟ แถบ REGEN ตอนเบรก เตือนระยะเหลือน้อย
  จัดกรุ๊ป (เช่น บ้าน, รถ) หน้ารายการแยกกรุ๊ปพร้อมยอดรวม
- แอนิเมชัน: เว็บ (วงแหวน SOC, ไฟไหล, ตัวเลขหมุน, กราฟลากเส้น ฯลฯ) และจอ CYD ทั้งสองแบบ
- หน้าเฟิร์มแวร์บนเว็บ (ปุ่ม ⬇️ ด้านบน): ติดตั้งผ่าน USB บนเว็บ (บอร์ดใหม่) · อัปเดตผ่านบลูทูธ · ดาวน์โหลด · คู่มือ 8 หมวด
- จอ Cloud Screen: CONTROL ของแบงก์ เลือกลูก #0..#4 แล้วตั้งค่า/MOS ได้ · BOARD -> AUTO MATCH

v2.8.1 - ชื่อบอร์ดตามฮาร์ดแวร์ + ตั้งค่าครั้งแรกด้วยคอมพิวเตอร์:
- ชื่อ Wi-Fi และบลูทูธ = BATTLAB-XXXXXX (6 หลักท้ายของ MAC ชิป ตรงกับบรรทัด MAC: ตอนติดตั้ง)
  ดู Hardware ID ได้ที่ เว็บ (ข้อมูลบอร์ด) · จอ CYD หน้า INFO · Cloud Screen SETUP -> PAIRING
- ตั้งค่าครั้งแรกโดยไม่ใช้มือถือ (Chrome / Edge บนคอมพิวเตอร์):
  1) ปุ่ม ⬇️ เฟิร์มแวร์ -> เลือกบอร์ด -> ผ่านสาย USB -> ติดตั้ง
  2) ติดตั้งเสร็จ กด Connect to Wi-Fi ใส่ Wi-Fi บ้าน
  3) กด Visit device -> เว็บเพิ่มบอร์ดเข้าบัญชีให้เอง
  บอร์ดที่ติดตั้งแล้ว: ปุ่ม "ตั้งค่าผ่าน USB" (หน้าแรก / อุปกรณ์ของฉัน) ได้หน้าตั้งค่าเหมือนบลูทูธ
- Windows: จอ CYD ต้องลงไดรเวอร์ CH340 ครั้งแรก · บอร์ด S3 ใช้ช่อง USB (ไม่ใช่ UART) ไม่ต้องลงไดรเวอร์

v2.8.2 - พลังงานรวมเป็นกรุ๊ป (cloud + บนบอร์ด):
- บอร์ดนับพลังงานวันนี้เอง (kWh ชาร์จเข้า / จ่ายออก) จาก V x I ทุก 1 วินาที เริ่มนับใหม่ทุกเที่ยงคืน
  (ใช้เวลาจาก Wi-Fi) เก็บลงหน่วยความจำทุก 10 นาที ไฟดับแล้วไม่หาย ส่งขึ้น cloud เป็น ein / eout
- เว็บ: หัวกรุ๊ปในหน้ารายการแสดง กำลังไฟรวม · SOC เฉลี่ย (ถ่วงตามความจุ) · kWh คงเหลือ · วันนี้ +เข้า/-ออก
  กด "ภาพรวม ›" ที่หัวกรุ๊ป = หน้าภาพรวมกรุ๊ป: การ์ดยอดรวม, กราฟกำลังไฟรวม 24 ชม., พลังงานรายวัน 7 วัน, รายการแบต
  ด้านบนสุดของหน้ารายการแสดงยอดรวมทุกเครื่อง
- จอ Cloud Screen หน้า ALL: แถบเลือกกรุ๊ป (ALL / ชื่อกรุ๊ป) + บรรทัดยอดรวมของกรุ๊ปที่เลือก
  SHOW (หมุนอัตโนมัติ) หมุนเฉพาะในกรุ๊ปที่เลือก
  ชื่อกรุ๊ปบนจอต้องเป็นภาษาอังกฤษ ถ้าเป็นภาษาไทยจอจะแสดงเป็น G1, G2 ...
- หน้าเว็บในบอร์ด S3 (192.168.4.1): การ์ด "พลังงานวันนี้" และ "ทั้งแบงก์" (ตารางทุกลูกบน RS485)
- จอ CYD (ต่อ BMS ตรง): หน้า HOME บรรทัดล่างสลับทุก 4 วินาที ระหว่างเวลาที่เหลือ กับ +เข้า/-ออก kWh วันนี้
- รายการบลูทูธ/Wi-Fi ที่ค้นเจอ ส่งเป็นหน้า ๆ ได้สูงสุด 30 รายการ (เดิมตัดเหลือไม่กี่รายการ)

v2.8.3 - BMS JK โมดูลบลูทูธรุ่นใหม่ + หน้าตาใหม่:
- เชื่อมต่อ JK ที่ใช้โมดูลบลูทูธรุ่นใหม่ (ZX-D30, MAC ขึ้นต้น A4:C1:38): รอโมดูลพร้อมก่อนส่งคำสั่ง,
  ถามแบบ JK ก่อน (0x97/0x96 ที่ FFE1 สลับแบบ write/no-response), ไม่ยุ่งกับบริการ FEE7 ของโมดูล
- ถ้ายังไม่ได้ข้อมูล บอร์ดส่ง "ข้อมูลตรวจสอบบลูทูธ" ขึ้น cloud (GATT, ไบต์ที่รับได้, ข้อมูลล่าสุด)
  ดูได้ที่เว็บ -> หน้าภาพรวมของบอร์ด -> "ข้อมูลตรวจสอบบลูทูธ"
- เว็บ Cloud หน้าภาพรวม: เลือกหน้าตาได้ 4 แบบ (พลังงานไหล / เรียบสะอาด / ห้องนักบิน / แบบเดิม) จำแยกต่อบอร์ด
- หน้าเว็บในบอร์ด (192.168.4.1): ธีมมืดแบบเดียวกับ cloud, เลือกหน้าตา 3 แบบ, แบงก์แสดงเป็นแถวต่อลูก,
  มือถือมีแถบเมนูด้านล่าง (หน้าในบอร์ดไม่มีเน็ต จึงใช้ฟอนต์ของเครื่อง)
- เว็บ Cloud: แก้หน้าควบคุม/ตั้งค่ารีเฟรชทับค่าที่กำลังพิมพ์

v2.8.4 - JK โมดูลใหม่ ZX-D30 (ต่อ):
- ถ้า BMS ส่งข้อมูลเซลล์ครั้งละเฟรม บอร์ดจะขอซ้ำ (0x96) ทุก 2 วินาที แทนการรอ 10 วินาที
- ลองส่งคำสั่งเฉพาะช่องข้อมูลของ BMS (FFE0 / FF00 / FFF0) เท่านั้น ไม่ยุ่งกับช่องอัปเดตเฟิร์มแวร์ของโมดูล (FE59)
- ข้อมูลตรวจสอบบน cloud เพิ่ม: จำนวนเฟรมแต่ละชนิด, เฟรมเซลล์ล่าสุด, จำนวนครั้งที่หลุด, MTU

v2.8.5 - JK โมดูลใหม่ (ต่อ):
- BMS ที่ใช้ช่อง FFE0 ได้รับเฉพาะคำสั่ง JK ใน 60 วินาทีแรก (ANT จะถูกลองเมื่อชื่อขึ้นต้น ANT หรือ JK ไม่ตอบ)
- ไม่ส่งคำสั่งทดลองหลายแบบใส่ BMS ที่ใช้ช่อง FFE0 อีก (อาจทำให้ JK รุ่นใหม่ค้างจนต้องรีสตาร์ท BMS)
- เปิดรับข้อมูลเฉพาะ FFE1 และเปิดแบบมีการตอบรับ (write with response)
- ถ้า BMS เคยค้างจากเวอร์ชันก่อน ให้รีสตาร์ท BMS 1 ครั้งหลังอัปเดต

v2.8.6 - กู้รหัส JK BMS:
- ลืมรหัสเชื่อมต่อบลูทูธ / รหัสตั้งค่าพารามิเตอร์ของ JK: บอร์ดอ่านรหัสเดิมจากข้อมูลรุ่นของ BMS ให้ดู
  หน้าเว็บในบอร์ด -> เชื่อมต่อ BMS -> "กู้รหัส JK BMS" · เว็บ Cloud -> ควบคุม -> "กู้รหัส JK BMS" (เฉพาะเจ้าของบัญชี)
  แบงก์ RS485 เลือกดูรายลูกได้ · รหัสซ่อนเองใน 30 วินาที
- ตั้งรหัสใหม่: ทำในแอป JK ด้วยรหัสที่กู้ได้ (บอร์ดยังไม่ส่งคำสั่งเปลี่ยนรหัส เพราะ JK ไม่เปิดเผยคำสั่งนี้)

v2.8.7 - ความจุ / เวลา ถูกต้อง + ลิงก์แชร์:
- แก้การอ่าน JK: ความจุคงเหลือ (Ah) อ่านจากตำแหน่งที่ถูก (เดิมไปอ่านความจุเต็ม) และส่งความจุเต็มแยกมาด้วย
  -> เวลาใช้ได้อีก / เวลาชาร์จเต็ม / kWh คงเหลือ / SOC เฉลี่ยแบงก์-กรุ๊ป (ถ่วงด้วยความจุเต็ม) ถูกต้อง ทั้งจอ CYD หน้าเว็บบอร์ด และ Cloud
- เว็บ Cloud: แชร์ลิงก์ดูอย่างเดียว (ตั้งค่า -> "แชร์ลิงก์ดูอย่างเดียว" หรือหน้าภาพรวมกรุ๊ป -> "แชร์ทั้งกรุ๊ป")
  คนที่ไม่มีบัญชีเปิดดูได้ (ภาพรวม เซลล์ กราฟ) ควบคุมไม่ได้ · ยกเลิกลิงก์ได้ทุกเมื่อ
